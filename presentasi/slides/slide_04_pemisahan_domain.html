LEVEL 1 · SUPERVISORY LAYER Cloud & Telemetri

Internet of Things (IoT) Domain

  • Protokol Data: Komunikasi publish/subscribe MQTT over TLS ke broker HiveMQ Cloud.
  • Non-Real-Time: Interval transmisi 2–5 detik; toleran terhadap delay internet dan jitter.
  • Fungsi Utama: Monitoring visual via web dashboard, logging histori gas/suhu, remote setpoint.
  • Isolasi Keamanan: Gangguan koneksi internet sama sekali TIDAK mengganggu kendali fisik lokal.
Sifat Eksekusi & Latensi: Non-Deterministik (~2s)
LEVEL 2 · LOCAL CONTROL LAYER Autonomous Closed-Loop

Sistem Kendali Tertutup (PID)

  • Sampling Deterministik: Loop kalkulasi PID diskrit dieksekusi stabil tiap 50 ms (20 Hz).
  • Pemrosesan Lokal Silikon: Berjalan mandiri pada ESP32 tanpa menunggu respons server luar.
  • Aktuasi Presisi: Hardware PWM 5 kHz mengendalikan MOSFET blower & sudut servo 0°–90°.
  • Kepatuhan Standar: Memenuhi prinsip sistem kontrol umpan balik kontinu (Standar Pertemuan 2).
Sifat Eksekusi & Latensi: Deterministik Keras (50ms)
